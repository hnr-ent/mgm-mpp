<h1 align="left">MPP</h1>

###

<p align="left">The MPP is a tool used for self-audit purposes only.<br>After the user has completed filling up the correct data/text of their work,<br>they can use this tool to validate the accuracy of their work by cross-matching what this tool is able to extract against their own work.</p>

###

<h3 align="left">What It Does/How To Use:</h3>

###

<p align="left">Once the user obtains a copy of the FINAL copy document, they will copy the entire content of said document<br>and paste it on the top textarea.<br>Along with it, the user must include add the following:</p>

###

<p align="left">Ticket URL: {received ticket url}<br>Creative Path: {provided creative path}</p>

###

<p align="left">Once the document content, ticket url, and creative path are placed, hit the Extract button and the input boxes will populate texts.<br>Compare your own work against this tool. If it matches, it's almost certainly that your work is 99% correct.</p>
