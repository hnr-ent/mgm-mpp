# MPP
$${\color{red}The \space MPP \space is \space a \space tool \space used \space for \space self-auditing \space purposes \space only.}$$
<br>
After the user has completed filling up the correct data/text of their work,
they can use this tool to validate the accuracy of their work by cross-matching what this tool is able to extract against their own work. 

## What It Does/How To Use:
Once the user obtains a copy of the FINAL copy document, they will copy the entire content of said document
and paste it on the top textarea.
Along with it, the user must include add the following:

Ticket URL: {received ticket url}
Creative Path: {provided creative path}

Once the document content, ticket url, and creative path are placed, hit the Extract button and the input boxes will populate texts.
Compare your own work against this tool. If it matches, it's almost certainly that your work is 99% correct.
